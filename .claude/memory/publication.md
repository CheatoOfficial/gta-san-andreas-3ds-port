# Publication boundaries

Read `LICENSE`, `NOTICE.md`, `docs/3DS_LEGAL.md`, `SECURITY.md` and `TAKEDOWN.md`.
Keep upstream license/notices unchanged and the required credit on every publication/release page.

The game-data guard is a heuristic. Its history mode scans blobs introduced beyond the pinned upstream base
on local refs, including deleted files. Missing history/base is a failure, not evidence of cleanliness.
Remote attachments, releases, un-fetched refs and content provenance need separate inspection.

No game builds, translated source, assets, screenshots, raw logs or links to copies may be published here.
Timing summaries must match an explicit numeric format and be reviewed before sharing.
Private vulnerability reporting must be enabled before advertising that route.

The current publication decision and remaining validation work belong in `docs/HANDOFF.md`.
